# Food Ordering Web App in C# (Visual Studio + Database)

This project is a web-based Food Ordering Application developed in C# using Visual Studio with a database backend for efficient data management. The application allows users to browse food items, manage their orders, and complete purchases through a secure checkout process.

# Key Features:

User-Side:
- Authentication: Login, signup, and forget password functionality.
- Product Browsing: View all available food items with images, descriptions, and prices.
- Cart Management: Add food items to the cart, increase or decrease quantities, or delete items.
- Checkout & Payment: Complete the order using a chosen payment method.

Admin-Side:
- Menu Management: Add, update, or delete food items from the menu.
- Order Oversight: View user orders and manage available items efficiently.
- Database Integration:
- All food items, user data, and orders are stored securely in the database to ensure data consistency and reliability.

This web app provides a complete solution for online food ordering by combining a smooth user experience with an admin management panel. Users can easily browse and purchase food items, while admins can manage the menu and monitor orders, making the system ideal for restaurants or food service businesses.

# Pre-requirements:

- Visual Studio IDE installed
- .NET Framework (version compatible with C# project)
- Database System (e.g., SQL Server)
